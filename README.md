# One Love, Two IDs

Y+ (yplus.ps) interactive story — first experience of the Communicating Palestine toolkit.

- `index.html` — the interactive (also as `One Love Two IDs.dc.html`)
- `toolkit-data.json` — all copy in EN / IT / FR / AR, sources, badge keys
- `support.js` — runtime
- `assets/yplus-logo.png`

Open `index.html` over HTTP (e.g. GitHub Pages) — it fetches `toolkit-data.json`.
